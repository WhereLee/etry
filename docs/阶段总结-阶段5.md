# 阶段5总结：权益与交付（书架 / 试读 / 下载 / 水印）

## 一、本阶段做了什么

### 功能清单
- **公开试读**：`GET /api/materials/{id}/preview`，游客可访问；只保留前 `previewPages` 页并叠加 45° 半透明「试读」水印；下架/不存在/未上传文件分别 404。
- **权益下载**：`GET /api/library/materials/{id}/download`，登录 + MATERIAL 活跃权益门槛（未购 403、游客 401）；完整 PDF 每页叠加「已购 · {昵称} · ID{userId}」水印；`Content-Disposition: attachment` 文件名=资料标题.pdf。**下架后已购仍可下载**（权益基于购买事实而非在售状态）。
- **已购书架**：`GET /api/library/materials`，权益表 listActive(MATERIAL) 与目录批量 join（无 N+1）；`downloadable=false` 标记文件缺失供前端置灰。
- **演示 PDF 懒生成**（PRD §1）：本地磁盘 `app.material-storage.root` 缺失文件时按 pageCount 生成示例 PDF；临时文件 + 原子移动落盘，并发只落一份；fileKey 归一化越界校验拒绝路径穿越。
- **前端**：资料详情页「免费试读 / 下载资料（已购时替换加购按钮）+ 已购水印提示」；学习空间新增「我的资料」书架（概览计数 + 卡片下载/试读 + 空态引导去商城）；`library.js` 裸 axios blob 下载（绕开 JSON 拦截器、解析 blob 错误体）。
- **中文字体**：PDFBox 标准 14 字体不含 CJK，随包 GB2312+ASCII 子集 `resources/fonts/material-cjk.ttf`（simhei 子集化，2.1MB）。

### 技术要点
- 交付加工与存储分离：`MaterialPdfFactory`（截页/水印/生成）纯函数式 byte[] 进出，`MaterialFileStore` 只管落盘与路径安全，`MaterialDeliveryService` 编排权益门槛与昵称拼装（identity.api 读端口）。
- 水印用 `PDExtendedGraphicsState` alpha 0.16 + `Matrix.getRotateInstance` 居中旋转，APPEND 模式不破坏原内容流。
- 并发懒生成：ATOMIC_MOVE 竞争失败（Windows 抛 AccessDeniedException）且目标已存在 → 直接读赢家文件，天然 grant-once 语义。
- 模块边界：ArchUnit 新增 `identityInternal()` 谓词，material 模块「禁内部实现、放行 api」，与 commerce 同构。

## 四、当前阶段的已知缺陷
- 演示 PDF 为项目自产示例内容（PRD 允许），运营真实上传链路留待阶段6 管理端。
- 下载为同步全量 byte[] 进出内存，超大文件（>百 MB）需流式改造；当前演示资料页数规模无压力。
- 水印为文本层叠加，可被专业工具去除；定位为演示追溯而非 DRM（PRD 口径）。
- 试读/下载未接 CDN/COS，域名部署阶段按需切换对象存储（阶段7）。
