# 阶段3总结：身份与目录接口（注册/RBAC/目录/购物车）

## 一、本阶段做了什么

### 后端
- **买家自助注册**：`POST /api/auth/register`（RegisterRequest：用户名 3-30、强密码、可选昵称），注册即登录返回 JWT；legacy 角色列沿用 STUDENT 兼容旧学习端，RBAC 授 BUYER；用户名重复/弱密码返回 400。
- **Spring Security 完整过滤链**：新增 identity/security/SecurityConfig（替代 platform/config 旧占位链），JwtAuthFilter 移入链内（addFilterBefore），禁用 servlet 二次注册；无状态、JSON 401/403、OPTIONS 放行；`@EnableMethodSecurity` 为阶段6 权限点做准备。
- **RBAC 权威注入**：JwtAuthFilter 解析 token 后按 t_user_role 注入 `ROLE_<rbacCode>` + 权限点权威；无 RBAC 记录回退 legacy 角色。RbacSeedContributor 预置 11 个权限点、4 个管理角色绑定，并给演示账号授角色。
- **公开资料目录**：`GET /api/materials`（分类筛选+分页，size 上限 50）、`GET /api/materials/search`（ngram 全文检索）、`GET /api/materials/{id}`（仅 ON_SALE，否则 404）；游客可读。
- **购物车接口**：`GET/POST /api/cart`、`DELETE /api/cart/{materialId}`；CartService 只依赖 material/entitlement 的 api 端口（ArchUnit 边界合规）；加购校验存在/在售/未购，重复加购幂等；列表叠加 onSale/purchased 标记，合计只计可售未购行。
- **权益中心泛化**：EntitlementStore/Service 全部商品维度方法改为显式 productType 入参（原硬编码 COURSE_SERIES），MATERIAL 与 COURSE_SERIES 共用同一套 grant/revoke/查询语义，对旧调用等价。

### 前端
- 注册页（前端校验：用户名长度、密码强度、二次确认一致）、登录页增加注册入口。
- 资料商城页：分类 tab、全文搜索、分页卡片列表；游客可浏览，加购引导登录（带 redirect 回跳）。
- 资料详情页：分类/学段/学科标签、页数、试读页数、价格、加购。
- 购物车页：已购买/已下架置灰标记、移除、可结算合计；Pinia cart store 统一状态，导航栏购物车角标。
- 路由与导航：`/` 落地页改为资料商城；学员导航加入商城/购物车；旧学习空间/课程商店入口保留（legacy 模块后续阶段退役）。

## 四、当前阶段的已知缺陷
- 购物车尚无结算入口（阶段4 交易闭环接入多商品下单）。
- 资料无真实文件/预览/下载（阶段5 本地存储 + PDFBox 试读 + 水印）。
- 管理端资料 CRUD 未做（阶段6，@PreAuthorize 权限点已就绪）。
- legacy 课程/学习模块与旧 RoleAspect 鉴权仍在运行，双轨并行属分阶段迁移，非简化。
- 真实支付宝 ¥0.01 验收待用户商户账号，当前 Mock 通道。
