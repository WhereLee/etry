# 教师内容管理与发布状态

更新日期：2026-11-02

状态：**批次 B 已实现**

## 1. 范围

批次 B 完成教师端系列、章节、视频元数据管理；视频上传由批次 C 单独实现。

- 教师可以创建和编辑自己的系列。
- 教师可以创建、修改、排序和删除章节。
- 教师可以创建、修改、排序和删除视频元数据。
- 教师可以发布、下架和归档自己的系列。
- 管理员只能分配已发布系列。
- 学员只能看到已分配且已发布的系列。

## 2. 系列状态

| 状态 | 含义 | 学员可见 |
|---|---|---|
| `DRAFT` | 草稿，内容可编辑 | 否 |
| `PUBLISHED` | 已发布，可分配 | 是，且必须已分配 |
| `ARCHIVED` | 已归档 | 否 |

发布条件：

- 至少一个章节；
- 至少一个视频；
- 所有视频 `media_status = READY`；
- 视频对象键不能为空。

任何章节或视频结构变更都会使已发布系列自动回到 `DRAFT`，避免学员看到未就绪内容。

## 3. 视频状态

`t_series_video.media_status`：

- `PENDING`：未就绪，通常表示还没有对象键；
- `READY`：已就绪，可以发布和播放。

批次 C 已接入 COS 直传：教师不能手工填写对象键，必须通过系统生成的上传地址上传文件，服务端确认对象后才会变为 `READY`。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/teacher/series` | 创建系列，默认草稿 |
| `PUT` | `/api/teacher/series/{id}` | 修改系列标题、简介、排序 |
| `PUT` | `/api/teacher/series/{id}/status` | 发布、下架、归档 |
| `POST` | `/api/teacher/series/{seriesId}/chapters` | 创建章节 |
| `PUT` | `/api/teacher/series/{seriesId}/chapters/{chapterId}` | 修改章节 |
| `DELETE` | `/api/teacher/series/{seriesId}/chapters/{chapterId}` | 删除空章节 |
| `POST` | `/api/teacher/series/{seriesId}/chapters/{chapterId}/videos` | 创建视频元数据 |
| `PUT` | `/api/teacher/series/{seriesId}/chapters/{chapterId}/videos/{videoId}` | 修改视频元数据 |
| `DELETE` | `/api/teacher/series/{seriesId}/chapters/{chapterId}/videos/{videoId}` | 删除视频 |

所有接口都要求 `TEACHER` 角色，并在 Service 层校验系列归属。

已有种子系列和已有视频自动标记为已发布/已就绪。

## 6. 前端

- `/teacher/series`：系列列表和状态。
- `/teacher/series/new`：新建系列。
- `/teacher/series/:id/edit`：系列编辑器。
- `/teacher/series/:id`：只读详情和编辑入口。

编辑器支持：

- 修改系列标题、简介、排序；
- 添加/编辑/删除章节；
- 添加/编辑/删除视频元数据；
- 选择视频文件直传 COS，显示上传进度；
- 发布、下架、归档。

## 7. 验收

已验证：

- 无视频不能发布；
- 未就绪视频不能发布；
- 视频就绪后可以发布；
- 发布后管理员可分配；
- 学员可以看到拥有有效权益的系列；
- 修改结构后系列自动回到草稿；
- 草稿状态下新学员不可见，已有权益的学员仍可访问；
- 有视频的章节不能直接删除；
- 归档后停止新分配和新销售，已有权益的学员仍可访问；收回必须显式撤销权益。
