# 管理员内容治理

更新日期：2026-11-02

状态：**批次 E 已实现**

## 1. 目标

管理员掌握全平台内容状态，但不替代教师编辑课程。

能力：

- 查看全部系列；
- 按关键词、发布状态筛选；
- 查看教师归属、章节/视频数、分配学员数；
- 查看系列详情和视频媒体状态；
- 下架已发布系列；
- 归档草稿或已发布系列。

管理员不能直接发布教师系列，也不能编辑章节和视频。

## 2. 状态操作

| 当前状态 | 管理员可执行 |
|---|---|
| `DRAFT` | 归档 |
| `PUBLISHED` | 下架为草稿、归档 |
| `ARCHIVED` | 不允许直接发布；由教师恢复草稿 |

下架和归档都会使系列从学员学习空间消失。管理员不能绕过内容准备和发布校验直接发布。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/admin/content/series` | 全部系列分页和筛选 |
| `GET` | `/api/admin/content/series/{id}` | 系列详情 |
| `PUT` | `/api/admin/content/series/{id}/status` | 下架或归档 |

筛选参数：

- `keyword`：系列标题、教师昵称或账号；
- `status`：`DRAFT / PUBLISHED / ARCHIVED`；
- `teacherId`：可选；
- `page` / `size`。

## 4. 审计

状态操作记录：

- 操作管理员；
- 动作 `ADMIN_SERIES_STATUS`；
- 目标系列 ID；
- 成功/失败；
- traceId。

## 5. 前端

管理员导航新增 `/admin/series`：

- 系列列表；
- 状态筛选；
- 查看详情弹窗；
- 下架/归档确认弹窗；
- 分页。

## 6. 验收

- 管理员可以查看全部系列和教师归属；
- 可查看章节、视频媒体状态和文件大小；
- 已发布系列可以下架；
- 下架后停止新销售和新分配，已有权益的学员仍可访问；
- 管理员直接发布返回 `400`；
- 教师访问管理接口返回 `403`；
- 状态变化写入管理员审计。
