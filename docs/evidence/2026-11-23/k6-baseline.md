# k6 压测基线（2026-11-23）

## 环境
- 4C / 3.7G；Docker：MySQL 8 / Redis 7 / 后端（640M 限额）；宿主 nginx 未参与本次加压。
- BASE_URL：`http://127.0.0.1:8084`（直连后端，排除 TLS/nginx 开销）。
- 读场景混合：80% 目录、15% 搜索、5% 试读 PDF；登录为 BCrypt 路径；订单为鉴权读。

## 资源与瓶颈
- 100 VU 读结束后：backend **587.2/640MiB**、MySQL **482.2/512MiB**、Redis 4.3MiB；宿主可用 1.88G。
- 登录/订单后：backend **596.1/640MiB**、MySQL 482.6/512MiB；宿主可用 1.87G。
- 结论：延迟与错误率良好；**内存限额是当前瓶颈**，backend 已达 93%、MySQL 94%。
- 登录：p95 158ms，BCrypt 中位约 84ms，属预期 CPU 成本；正确密码未被限流计数。

## 未做与后续
