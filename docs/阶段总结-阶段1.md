# 阶段1总结：依赖接入、国内镜像与 CI 加固

## 一、本阶段做了什么
- 后端依赖：spring-boot-starter-security（完整 starter）、springdoc-openapi 2.6.0、PDFBox 3.0.3、EasyExcel 4.0.3
- SecurityConfig 行为保持接入：无状态 + permitAll，认证仍由 JwtAuthFilter 执行；完整 RBAC 留待身份阶段替换 permitAll（非简化，是分期落地）
- springdoc 开关：`API_DOCS_ENABLED` 环境变量可在生产关闭 api-docs/swagger-ui
- 前端依赖：pinia ^2.2.6、pdfjs-dist ^4.8.69（购物车/预览阶段使用）
- ESLint 9 flat config 接入（eslint-plugin-vue flat/recommended），清理 2 处死代码，--fix 格式修复
- 国内镜像：本机 Maven 已配阿里云（~/.m2/settings.xml）、Docker 内 Maven 已配阿里云（server/docker/maven-settings.xml）；新增 web/.npmrc 固化 registry.npmmirror.com（本地与 Docker 前端构建一致）。本机未装 Docker，Docker Hub 拉取镜像源属宿主机 daemon 配置，部署阶段在服务器上做
- CI 加固：concurrency 取消重复运行、各 job timeout、后端 package 验证、JaCoCo 报告产物上传（14 天）、前端 lint 门禁、新增 docker-build job（compose build 验证两个镜像）、checkout/setup-node 升 v5
