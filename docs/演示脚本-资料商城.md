# 演示脚本：学习资料商城（Mock 全链路）

面向面试演示的端到端走查脚本。默认 Mock 支付，无需支付宝商户凭据即可跑通「注册 → 浏览试读 → 购物车 → 下单支付 → 权益交付 → 书架下载 → 退款申请 → 客服审批 → 权益回收」完整闭环。

## 0. 准备

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\start-local.ps1
```
- 前端 `http://127.0.0.1:5175`，后端 `http://127.0.0.1:8084`。
- 确认 `PAYMENT_PROVIDER=mock`（默认）。
- 演示账号：`admin`（SUPER_ADMIN）、`teacher`（OPERATOR）、`student`（BUYER）；初始密码见启动日志或 `SEED_*_PASSWORD`，首次登录强制改密。
- 种子资料 5 份（4 在售 + 1 下架），PDF 由项目惰性生成。

## 1. 买家自助注册
1. 访问 `/register`，注册新买家（如 `demo_buyer` / 密码 `Demo#Buyer2026`）。
2. 预期：注册即登录（无需首改密），跳转商城；后端 legacy 角色 `STUDENT`、RBAC 授 `BUYER`。
3. 讲解点：不开放运营自助注册，买家可自助注册；弱口令（如 `123`）被 400 拦截「密码需为 8-32 位，且同时包含字母和数字」。

## 2. 目录浏览 / 搜索 / 试读
1. `/materials`：分类筛选（试卷/教辅/讲义/课本）、分页。
2. 搜索「函数」→ 命中数学试卷（ngram 全文索引）。
3. 点开详情 `/materials/:id` → 「试读」：游客可看前 N 页，叠加「试读」水印。
4. 讲解点：试读截页 + 试读水印无需登录；下架资料（化学手册）详情 404「资料不存在或已下架」。

## 3. 购物车 → 多明细订单
1. 详情页「加入购物车」，加购 2 份不同资料。
2. `/cart`：勾选结算 → 生成**一笔多明细订单**。
3. 讲解点：购物车结算合并为单订单多 item，价格以分为单位（`priceCents`）避免浮点误差。

## 4. Mock 支付 → 异步履约
1. 订单详情 `/orders/:orderNo` → 去支付 `/mock-pay/:orderNo`。
2. Mock 收银台「确认支付」→ 支付成功。
3. 预期：订单 `PAID → FULFILLED`，发件箱异步发放权益（`t_entitlement` ACTIVE）。
4. 讲解点：支付尝试 attempt + 支付事件幂等 + outbox 异步履约；Mock 通知验签（`mock-secret`），与支付宝共用同一内核。

## 5. 资料书架 → 水印下载
1. `/learning`：已购资料书架列出刚买的两份。
2. 「下载」→ 带**购买者水印**的完整 PDF。
3. 讲解点：下载经权益门槛（`EntitlementQuery.hasActive`），叠加买家水印；**只认权益不认在售状态**——运营下架后已购仍可下载。

## 6. 买家退款申请
1. 订单详情 `/orders/:orderNo` → 「退款申请」，填理由提交。
2. 预期：`t_refund_request` 生成 PENDING（每订单唯一）；买家端状态显示「待处理」。

## 7. 客服审批（运营端订单页 AdminOrders）
1. 用 `admin` 登录 → `/admin/orders`，退款申请审批区。
2. 「拒绝」（弹窗必填拒绝理由，将展示给买家）→ 买家端可见理由（状态「已拒绝」）→ 买家「再次申请」重置为 PENDING。
3. 「同意」→ 触发全额退款：订单 `REFUNDED`、权益 `REVOKED`、`t_refund` 恰好一笔（状态「已同意」）。
4. 讲解点：审批用条件认领（`UPDATE ... WHERE status='PENDING'`）防并发重复审批；退款内核状态守卫 + 锁 + 唯一退款行。

## 8. 运营端 RBAC 走查
1. `admin`（SUPER_ADMIN）：资料管理 / 订单 / 对账 / 审计 / 用户角色全可见。
2. `teacher`（OPERATOR）：仅资料管理（`material:*`），访问订单/退款接口 → 403「没有权限执行该操作」。
3. 用户角色页给某账号授 `CUSTOMER_SERVICE` → 该账号**同 token 即时**获得 `order:read/refund:operate/user:read`（每请求从库读权限）。
4. 审计日志页：资料上下架、退款审批、角色授予等关键动作留痕。
5. 对账页：财务导出（EasyExcel）。

## 9. 并发安全（可选，集成测试佐证）
- `RefundConcurrencyIntegrationTest`：10 线程并发退款 → `t_refund` 恰好 1 笔、权益恰好回收 1 次、订单终态 REFUNDED。
- 讲解点：并发下「晚到调用被状态守卫合法拒绝」与「窗口内调用幂等返回同一笔」都正确，安全不变量与调度无关。

## 10. 安全收口（可选，HTTP 实测）
- 响应头：CSP / nosniff / DENY / no-referrer / Permissions-Policy（HSTS 仅 HTTPS）。
- CORS：未知来源不回显 ACAO；白名单回显 ACAO + 允许凭据。
- 登录限流：连续失败 8 次 → 429。

## 收尾
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\stop-local.ps1
```
