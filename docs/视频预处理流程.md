# 视频预处理流程

> 适用：btry 学习空间  
> 目标：把原始 MP4 转成 faststart 版本，并安全替换 COS 对象。

## 1. 准备 ffmpeg

本机没有 ffmpeg 时，可用清华 PyPI 镜像安装便携版：

```powershell
$target = Join-Path $env:TEMP "etry-ffmpeg-py"
python -m pip install --no-cache-dir --target $target -i https://pypi.tuna.tsinghua.edu.cn/simple imageio-ffmpeg
$env:PYTHONPATH = $target
python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"
```

拿到路径后，把它作为 `-Ffmpeg` 参数传入。

## 2. 执行 faststart 预处理

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File tools\prepare-video.ps1 `
  -Source "C:\path\input.mp4" `
  -Destination "C:\path\faststart.mp4" `
  -Ffmpeg "C:\path\ffmpeg.exe"
```

脚本会：

- 执行无损重封装：`-c copy -movflags +faststart`
- 检查文件大小
- 检查文件头 64 KB 是否包含 `moov`
- 检查文件尾 2 MB 是否不再包含 `moov`
- 校验失败时直接报错

## 3. 上传为新的 COS 对象

不要覆盖原对象。建议新 key：

```text
edu/video/{teacherId}/{name}-faststart.mp4
```

设置对象元数据：

```text
Content-Type: video/mp4
Cache-Control: private, max-age=3600
Content-Disposition: inline
```

上传后验证：

- `HEAD` 或 Range 请求返回 `206`
- `Content-Type` 为 `video/mp4`
- `Cache-Control` 包含 `private, max-age=3600`
- 文件头 64 KB 包含 `moov`

## 4. 更新数据库

先确认哪些课时引用旧对象：

```sql
SELECT id, title, video_key
FROM t_series_video
WHERE video_key = '<old-key>';
```

再更新：

```sql
UPDATE t_series_video
SET video_key = '<new-faststart-key>'
WHERE video_key = '<old-key>';
```

如果当前是演示数据，确保 `SAMPLE_VIDEO_KEY` 默认值也同步更新。

## 5. 回滚

旧对象不要立即删除。若新对象播放异常，把 `video_key` 改回旧 key 即可。

## 6. 验收

- 播放首帧正常
- 拖动到 50% / 90% 正常
- Range 返回 206
- `moov` 在文件头
- 播放日志无连续 `ERROR` / `STALLED`
- URL 缓存命中正常
